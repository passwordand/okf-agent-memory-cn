# OKF Agent Memory 中文检索版 v0.4.3-cn.1

> 基于上游 OKF Agent Memory v0.4.3，保留中文检索与双库显式初始化。

## 本版相对 v0.3.1-cn.4

- 合入上游 v0.4.0 至 v0.4.3 的加密 vault、Hub 同步、原子写入、严格校验和安全修复。知识库仍使用 OKF v0.2 Markdown 结构，已有库无需迁移。
- 保留 `gse` 中文分词及中英文混合检索；保留无参数 `okf init` 创建 `./knowledge/`、显式 `okf_init()` 和双库 wrapper 的项目 / 全局隔离。
- 七个 MCP 工具都声明 object 类型的 `outputSchema`。成功调用返回 `structuredContent`，包括 `okf_init` 的状态和实际知识库路径；错误调用继续返回 `isError`。
- 缺少项目知识库时 MCP 仍可连接；只有 Agent 显式调用 `okf_init()` 才创建 `index.md` 与 `log.md`。普通连接、读取和搜索不自动创建文件。
- 源码构建要求 Go 1.26。CLI、MCP、中文检索、双库 wrapper、vault 和 Hub 均有回归测试。

## 升级本机 Agent

从本 Release 下载对应平台的 `okf` 二进制。使用双库 wrapper 时，同步更新已安装的 `examples/dual-mcp/mem-mcp.js`，然后重启 Codex、OpenCode、DeepSeek Harness 或其他 MCP 客户端。现有 `knowledge/` 内容无需改动。
