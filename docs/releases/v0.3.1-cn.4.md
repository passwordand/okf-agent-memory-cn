# OKF Agent Memory 中文检索版 v0.3.1-cn.4

> 基于上游 OKF Agent Memory v0.3.1，保留 `gse` 中文分词。

## 本版相对 v0.3.1-cn.3

- 新增 MCP 工具 `okf_init()`：项目知识库不存在时服务仍可连接；只有用户明确要求初始化、Agent 显式调用工具后，才创建 `knowledge/index.md` 和 `knowledge/log.md`。连接、读取和搜索失败均不会自动创建文件。
- 双 MCP wrapper 支持缺少项目库的首次接入。显式 `--project-root` 优先；未指定且找不到已有库时使用启动工作目录。全局库仍与项目库隔离，缺少全局库时继续报错。
- 无参数 `okf init` 现在固定创建 `./knowledge/`；需要旧版根目录布局时，显式运行 `okf init .`。无参数 `okf mcp` 在全新项目中绑定 `./knowledge/`，已有根目录库仍可使用。
- 初始化保留已有文件，拒绝不安全的 symlink 和越界路径，并在现有根索引未声明 OKF v0.2 时返回错误。
- 补充 CLI、MCP、wrapper 回归测试，更新 Agent Skill、模板和接入文档。

## 升级

从 [GitHub Releases](https://github.com/passwordand/okf-agent-memory-cn/releases/tag/v0.3.1-cn.4) 下载对应平台二进制。使用双库方案时，同时更新 `examples/dual-mcp/mem-mcp.js` 的已安装副本，然后重启 MCP 连接。已有知识库无需迁移。

`okf_init()` 只创建知识库；完整 Skill、`AGENTS.md` 和 `Makefile` 仍由 `okf bootstrap` 安装。
