# OKF Agent Memory 中文检索版 v0.3.1-cn.3

> 基于上游 [OKF Agent Memory v0.3.1](https://github.com/okf-memory/okf-agent-memory/releases/tag/v0.3.1)，保留 `gse` 中文分词。

上游源码：https://github.com/okf-memory/okf-agent-memory

## 本版相对 v0.3.1-cn.2

- 继续修复上游 [issue #30](https://github.com/okf-memory/okf-agent-memory/issues/30) 的遗留部分：删除 `okf_show` / `okf_validate` 的 object `outputSchema`。
- 原因：MCP 规范要求声明了 `outputSchema` 的工具必须返回与之匹配的 `structuredContent`，而本服务端只返回 `content[].text`。严格客户端（OpenCode 等）在**调用时**会报 `Tool has an output schema but did not return structured content` 并使调用失败——cn.2 只解决了 `tools/list` 阶段的拒收，没解决调用阶段的校验。
- 至此 6 个 MCP 工具全部不声明 `outputSchema`，与上游 v0.2.0 行为一致；工具名、入参、返回文本均不变，知识库无需迁移。
- `structuredContent` 待上游 issue #30 正式实现后再评估是否跟随。

`v0.3.1-cn.2` 在严格客户端上 `okf_show` / `okf_validate` 调用会失败，请直接跳到本版本。`v0.3.1-cn.1` 在严格客户端上整个工具列表都加载不出来。

## 安装

前往 [GitHub Releases](https://github.com/passwordand/okf-agent-memory-cn/releases/tag/v0.3.1-cn.3) 下载对应平台二进制，重命名为 `okf` / `okf.exe` 后运行 `okf version`。
