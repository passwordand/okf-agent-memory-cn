### 🔐 Foundational Vault Crypto & Sync Engine (v0.4.0-rc.1)

> **Pre-release Candidate:** This build stabilizes `pkg/vault` and `pkg/sync` APIs and serves as the integration target for `okf-memory-hub`.

This release candidate introduces the foundational building blocks for encrypted, remote knowledge synchronization:

- **pkg/vault**: Zero-Knowledge bundle encryption using Argon2id key derivation and AES-256-GCM authenticated envelopes with content-addressed asset trees.
- **pkg/sync**: Low-overhead sync protocol for push/pull reconciliation against blind CAS backends.

**Does this change existing workflows?**
No. `okf-agent-memory` remains 100% local-first. The core library (`pkg/okf`) continues to have **0 external dependencies** and relies exclusively on the Go standard library. Your local Markdown bundles and Git-based workflows work exactly as before.

**Dependency Policy Clarification:**
To deliver state-of-the-art Argon2id key derivation for zero-knowledge vault synchronization, `pkg/vault` relies on the official Go sub-repository `golang.org/x/crypto`. The project maintains a strict **zero third-party dependency policy**—no external vendor libraries, external frameworks, or CGo dependencies are permitted.

**Status:**
RC.1 is feature-complete for cryptographic primitives. Final `v0.4.0` tag follows immediately after end-to-end verification with the Hub CAS server.
