# OKF Agent Memory v0.3.1 — DMAA Benchmark Engine, CLI Robustness & AAG Skill Alignment

> **Maintenance & Benchmarking Release:** Dual-Memory Agent Architecture (DMAA) empirical benchmark suite, CLI subcommand help handlers, Pre-Flight GPU Warmup, automated Mermaid sanitization, AAG v0.1 skill migration, and performance hardening.

We are pleased to announce **OKF Agent Memory v0.3.1**! Following the major v0.3.0 milestone that introduced Agent Action Grammar (AAG) and the Dual-Memory Agent Architecture (DMAA), this release provides the empirical benchmarking toolchain, resolves critical CLI edge cases, aligns our agent skills with AAG, and hardens performance.

---

## 🌟 Highlights & Key Improvements

### 1. Dual-Memory Agent Architecture (DMAA) Benchmark Engine (`okf-benchmark`)
To scientifically quantify the token and latency savings of DMAA over monolithic status-quo patterns, v0.3.1 introduces a pure Go automated benchmark suite ([Methodology Guide](../guides/BENCHMARKING_METHODOLOGY.md)):

* **Layer 1 Benchmark (`-suite push`)**: Evaluates Working Memory steering tax by comparing conversational English rules (`.cursorrules`) against compact **Agent Action Grammar** (`AGENTS.md`).
* **Layer 2 Benchmark (`-suite pull`)**: Evaluates Knowledge Memory context bloat by comparing monolithic documentation dumps against **OKF Progressive Disclosure** (in-memory BM25 retrieval).
* **Unified DMAA Suite (`-suite dmaa`)**: Measures end-to-end impact of combining both layers on real inference endpoints.
* **Authentic Empirical Testing Only**: Completely eradicated synthetic `--dry-run` and mock data fallbacks. The runner strictly evaluates live models and exits with clean diagnostics on unreachable endpoints.
* **Pre-Flight Warmup Ping (`-warmup=true`)**: Automatically primes GPU compute pipelines, Metal context buffers, and KV-caches prior to measurement, ensuring fair and comparable prefill latency (TTFT) metrics.
* **Automatic Mermaid Diagram Sanitizer**: Built-in AST sanitizer repairs unquoted labels with braces/quotes, normalizes subgraph IDs, and strips empty whitespace lines to guarantee error-free rendering in Markdown viewers.

#### 📊 Empirical Results (Apple Silicon M2 Pro, Qwen 2.5/3 Coder):
* **-76.0% Context Tax Reduction**: Drops average prompt context from 3,742 tokens down to 897 tokens per agent turn.
* **4.0x Faster Time-To-First-Token (TTFT)**: Prefill latency drops from ~10.4s to ~2.6s.
* **2.0x Faster Turn Completion**: Halves end-to-end execution time while maintaining **100% deterministic rule adherence**.

### 2. CLI Subcommand Help & UX Robustness
Autonomous coding agents frequently query subcommands with `--help` (e.g. `okf create --help` or `okf update --help`), which previously risked creating literal files named `--help.md`.

* **Dedicated Subcommand Help Handlers**: `okf create --help`, `okf update --help`, `okf search --help`, and `okf show --help` now intercept help flags and display contextual CLI usage instead of executing file mutations.
* **Argument Boundary Hardening**: Subcommands strictly reject hyphenated arguments (e.g. `--invalid-flag`) from being parsed as concept IDs, preventing accidental concept creation or directory corruption.

---

### 3. Agent Skill Migration to Agent Action Grammar (AAG v0.1)
Dogfooding our own specification, the canonical **`okf-memory`** agent skill has been refactored into AAG v0.1:

* **Strict Token Budget Compliance**: `.agents/skills/okf-memory/SKILL.md` reduced to **374 tokens** (under the 400-token budget).
* **Deterministic Guard Clauses**: Replaced conversational prose with RFC 2119 invariants (`MUST`, `NEVER`, `PREFER`) and condition triggers (`ON edit(@path/) => IF first_visit ...`).
* **Cross-Agent Parity**: SSoT symlinks verified across Claude Code, Cursor, Windsurf, and Copilot.

---

### 4. Performance & Security Hardening
* **Pre-Compiled Replacer in Concept Mutation**: `RelateConcepts` in `pkg/okf/mutate.go` now leverages a pre-compiled `strings.Replacer` for newline sanitization, reducing allocation overhead during relationship updates.
* **Gosec G304 Resolution**: Path resolution in benchmark test fixtures refactored to use clean paths and eliminate static analysis taint warnings.
* **Unit Test Coverage**: Extended test coverage for core types and boundary validation in `pkg/okf/types_test.go` and `cmd/okf/main_test.go`.

## 🚀 Getting Started with v0.3.1

### Install or Upgrade via Go:
```bash
go install github.com/okf-memory/okf-agent-memory/cmd/okf@v0.3.1
```

### Run the Empirical DMAA Benchmark:
```bash
# Run against local LM Studio server (default: http://localhost:1234)
go run ./cmd/okf-benchmark -suite dmaa

# Run against OpenAI or Anthropic
go run ./cmd/okf-benchmark -p openai -m gpt-4o -suite dmaa
go run ./cmd/okf-benchmark -p claude -m claude-3-7-sonnet-20250219 -suite dmaa
```
