# OKF Agent Memory 中文检索版 v0.3.1-cn.2

> 基于上游 [OKF Agent Memory v0.3.1](https://github.com/okf-memory/okf-agent-memory/releases/tag/v0.3.1)，保留 `gse` 中文分词。

上游源码：https://github.com/okf-memory/okf-agent-memory

## 本版相对 v0.3.1-cn.1

- 修复 MCP `tools/list` 被严格客户端拒绝的问题（继承自上游 [issue #30](https://github.com/okf-memory/okf-agent-memory/issues/30)，上游尚未修复）。
- 删除 `okf_search` / `okf_create` / `okf_update` / `okf_relate` 的非 object `outputSchema`。MCP 规范要求 `outputSchema` 根类型必须是 `object`；使用标准 MCP SDK 的严格客户端（新版 OpenCode 等）会因此校验失败、工具列表加载为空。握手本身不受影响，失败发生在 `tools/list` 阶段。
- `okf_show` / `okf_validate` 仍保留 object `outputSchema`。注意：服务端目前只返回 `content[].text`，尚未返回与该 schema 匹配的 `structuredContent`，这部分留待上游统一处理。
- 工具名、入参、返回文本均不变。现有 OKF v0.2 Markdown 知识库无需迁移。

`v0.3.1-cn.1` 在使用新版标准 MCP SDK 的客户端上会加载不到任何工具，请升级到本版本。临时绕过可继续用 `v0.1.5-cn.1`（无 `outputSchema`）。

## 安装

前往 [GitHub Releases](https://github.com/passwordand/okf-agent-memory-cn/releases/tag/v0.3.1-cn.2) 下载对应平台二进制，重命名为 `okf` / `okf.exe` 后运行 `okf version`。
