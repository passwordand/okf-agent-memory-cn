# v0.6.1-cn.1：上游升级、中文检索与双库隔离适配

本版将中文增强版从上游 v0.4.3 升级到 v0.6.1，保留 `gse` 中文分词、显式初始化及项目 / 全局双 MCP 方案。知识库继续使用 OKF v0.2，现有目录无需整体迁移。

## 新增与改进

- CLI / MCP 支持类型、状态、标签编辑，以及元数据过滤和到期检查。
- 支持知识包 Registry、`okf.lock`、`pull` / `restore` / `vendor` 与多层知识检索。
- 自定义列表字段按数组读写，更新时保留列表语义，支持成员过滤。
- 合入 BM25 词频与文档频率匹配一致性、短词匹配及词频上限修复。
- 合入 Hub 同步状态持久化，修复跨命令调用的状态丢失、冲突误判及重复上传问题。
- 加强人工验证来源、正文元数据及路径边界检查。

## 中文版兼容适配

- 保留 `gse` 搜索模式、编译时嵌入词典及中文 / 英文 / 数字查询。
- 保留无参数 `okf_init()`；缺库 MCP 可握手，但查询不自动建库、不回退全局库。
- 无参数 `okf init` 默认创建 `knowledge/`，`okf init .` 显式创建根目录库。
- 设置 `OKF_MCP_ROOT` 的 MCP 服务仅在绑定根目录内读取与写入。搜索只接受省略 scope、`bundle` 或 `project`；拒绝跨层 scope 和引用，工具 schema 同步声明范围。
- 现有双库 wrapper 已设置该环境变量，项目库、全局库和客户端入口可保持不变。独立未绑定根目录的 MCP 与 CLI 保留多层能力。
- Windows 通过文件句柄最终路径解析 junction，阻止库根目录、祖先目录或写入路径经 junction 越界。

## 升级注意事项

- 这是适配后的中文版，不建议用上游原版可执行文件替换中文部署。
- `--filter` 使用正式字段名 `tags`、`code_refs`、`description`；旧别名已移除。`--desc` 参数不变。
- 搜索分数和排序可能变化；同义口语的语义召回仍不作保证。
- 自定义列表 JSON 输出变为数组；接入方若曾把列表当字符串处理，需要调整。
- 运行中的 MCP 进程继续使用旧程序；更新后应重新连接 MCP 或重启对应客户端。
- 保留旧程序和 wrapper 备份即可回退核心使用流程。新版列表字段并不保证被旧版完整解释。

## 验证与发布

- 本次以 Windows 核心使用为发布验收范围，不追加 Linux / macOS 实机、race 或真实 Hub / Registry 联调。
- Windows 已完成 311 项 Go 测试（含子用例）、静态检查、6 项 wrapper 测试与 13 项真实 MCP 隔离测试；17 项按平台 / 权限跳过，另排除两项需文件符号链接权限的测试。
- 真实 wrapper / stdio MCP 覆盖旧版创建、新版更新、旧版读取、中文检索、元数据过滤、显式初始化、双库隔离与 junction 越界防护。
- GitHub CI 采用 Windows runner；发布流程保留各平台交叉构建，非 Windows 产物不代表经过实机验收。
