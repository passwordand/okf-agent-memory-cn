# OKF Agent Memory 中文检索版 v0.3.1-cn.1

> 基于上游 [OKF Agent Memory v0.3.1](https://github.com/okf-memory/okf-agent-memory/releases/tag/v0.3.1)，保留 `gse` 中文分词。

上游源码：https://github.com/okf-memory/okf-agent-memory

## 本版相对 v0.1.5-cn.1

- 对齐上游 v0.2.0 / v0.3.0 / v0.3.1：`code_refs`、`governance`、`okf_search.for_path`、AAG / DMAA、CLI `--help` 加固。
- 继续使用 `go-ego/gse` 处理中文和中英文混合检索；词典编译时嵌入。
- MCP 工具名不变（`okf_search` / `okf_show` / `okf_create` / `okf_update` / `okf_relate` / `okf_validate`）。
- 现有 OKF v0.2 Markdown 知识库无需迁移。

## 安装

前往 [GitHub Releases](https://github.com/passwordand/okf-agent-memory-cn/releases/tag/v0.3.1-cn.1) 下载对应平台二进制，重命名为 `okf` / `okf.exe` 后运行 `okf version`。
