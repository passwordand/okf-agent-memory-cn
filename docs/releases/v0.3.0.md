# OKF Agent Memory v0.3.0 — Agent Action Grammar & Dual-Memory Architecture

> **Major Milestone Release:** Introducing the Agent Action Grammar (AAG) RFC & AST Linter (`AAG-001`–`AAG-005`), Dual-Memory Agent Architecture (DMAA), Multi-Domain Codex Scaffolding, Single Source of Truth (SSoT) Tool Symlinks, and Autonomous Security Hardening.

We are excited to announce **OKF Agent Memory v0.3.0**! This milestone solves two of the most critical challenges facing autonomous AI coding agents: **token-bloat in instruction files** and **cognitive interference between working memory and long-term project knowledge**.

---

## 🌟 Highlights & Major Features

### 1. Agent Action Grammar (AAG) RFC & AST Linter (`AAG-001`–`AAG-005`)
Traditional AI agent instruction files (`AGENTS.md`, `CLAUDE.md`, `.cursorrules`) suffer from verbosity, ambiguous natural language, and uncontrollable context consumption.

OKF v0.3.0 introduces the **Agent Action Grammar (AAG)** ([RFC Specification](../spec/AGENT_ACTION_GRAMMAR_RFC.md))—a compact, deterministic, EBNF-based pseudocode language for AI agent rules:

```markdown
## 1. Behavioral Invariants & Constraints (RFC 2119)
- MUST execute `okf_search(query=keywords, limit=3)` before proposing architecture or dependencies.
- NEVER scan `knowledge/` via `list_dir`, `grep_search`, `find`, or raw file readers.
- PREFER native `okf_*` MCP tools OVER CLI fallback commands.

## 2. Guard Clauses & Scope Governance
- ON edit(@path/):
    IF first_visit(@path/) => okf_search(for_path=@path/)
    IF governance == "hold" => STOP("Subsystem frozen by governance.")
    IF governance == "constraint" => MUST adhere to all listed invariants
    IF governance == "context" => proceed with awareness
```

#### Key Benefits:
- **Up to 70% Token Savings**: Drastically reduces context-window overhead while improving rule adherence.
- **Deterministic AST Linting**: Built-in `okf agents lint` verifies 5 core rules:
  - `AAG-001` (ASCII-Only Invariance): Rejects token-wasting Unicode box art.
  - `AAG-002` (Explicit RFC 2119 Modals): Requires explicit modal verbs (`MUST`, `NEVER`, `PREFER`).
  - `AAG-003` (Tool Signature Integrity): Enforces strict function-like tool invocations (`tool(arg=val)`).
  - `AAG-004` (Mermaid Format Enforcement): Mandates Mermaid for all architectural diagrams.
  - `AAG-005` (Token Budget Gate): Strictly limits active working memory (default: 400 tokens).

### 2. Dual-Memory Agent Architecture (DMAA)
OKF v0.3.0 formalizes the **Dual-Memory Agent Architecture (DMAA)** ([RFC Specification](../spec/DUAL_MEMORY_AGENT_ARCHITECTURE_RFC.md)), establishing a clean separation of concerns between agent cognitive layers:

- **Layer 1: Working Memory (`AGENTS.md`)**: Compact (<400 tokens), push-loaded into every LLM request, strictly governed by AAG rules.
- **Layer 2: Domain Memory (`knowledge/`)**: Persistent, pull-on-demand knowledge graph (OKF v0.2 bundle) queried deterministically via BM25 / MCP tools.

---

### 3. Multi-Domain Codex Scaffolding (`okf agents init --domain=...`)
OKF Agent Memory is domain-neutral. OKF v0.3.0 ships with curated, pre-tested domain codices for diverse industries and applications:

- **`software`**: Engineering excellence, Clean Code, TDD, DRY, and security boundaries.
- **`books`**: Literature & editorial analysis, canon fidelity, timeline accuracy, and spoiler flagging.
- **`coaching`**: Executive coaching, client confidentiality, ICF core competencies, and goal progression.

Initialize any project with a single command:
```bash
okf agents init --domain=coaching --name="Executive Coaching Practice"
```

---

### 4. Single Source of Truth (SSoT) Tool Symlinks (`okf agents link`)
Never duplicate or drift agent instruction files across different IDEs and tools again.

A single canonical `AGENTS.md` automatically drives:
- **Anthropic Claude Code**: `CLAUDE.md` -> `AGENTS.md`
- **Cursor IDE**: `.cursorrules` -> `AGENTS.md`
- **Windsurf IDE**: `.windsurfrules` -> `AGENTS.md`
- **GitHub Copilot**: `.github/copilot-instructions.md` -> `../AGENTS.md`

Verify and repair symlinks instantly:
```bash
okf agents link --check
okf agents link --force
```

### 5. Unified CLI Governance (`okf validate --agents`)
The `okf validate` command now natively supports validating the complete agent memory stack:
```bash
# Validate both knowledge graph conformance AND agent governance in one step
okf validate --agents --strict .
```
Includes automatic detection and resolution of `knowledge/` subdirectories for project roots.

---

### 6. Security Hardening & Google Jules Remediation
- **Cross-Platform Path Sanitization (CWE-22)**: Neutralized POSIX/Windows backslash traversal vectors by normalizing paths via `filepath.ToSlash` prior to `filepath.Clean`.
- **Concept ID Validation**: Enforced upfront `ValidateConceptID` checks in `SaveConcept` to prevent directory traversal or control character injection.
- **Strict Static Analysis**: Fully compliant with `gosec` (0 issues) and `golangci-lint` (0 issues).
